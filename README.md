# Task 1 — Inconsistencies and Duplicates

I started with 39 rows and first profiled the dataset by checking its shape, data types, and the value counts of the categorical columns. I found inconsistent spellings and capitalization in faculty, club, and city values, so I stripped extra spaces, converted the values to lowercase, and then mapped each variant to its required canonical value, such as “Media Engineering and Technology” to “MET”, “Soccer” to “Football”, “Debating” and “Debate Club” to “Debate”, “Alex” to “Alexandria”, and “El Giza” to “Giza”. I also removed extra spaces from names, standardized their capitalization, converted emails to lowercase, mapped the different fee_paid values such as yes, Y, TRUE, 1, no, N, false, and 0 to boolean True or False, and parsed the two signed_up_at formats into one datetime column. After cleaning, I removed 3 exact duplicate rows, reducing the dataset from 39 to 36 rows. I then removed 4 repeated student-and-club sign-ups, keeping the latest submission because students sometimes submitted again to update their fee status, leaving 32 rows. The cleaning was done before this duplicate check because using the original club spellings would identify only 2 repeated sign-ups and leave 34 rows; variants such as “Music” and “music” or “Debate” and “debate club” would not match. Finally, I used student_id and club rather than names to identify repeated sign-ups, so two different students with the same name were not incorrectly merged.
